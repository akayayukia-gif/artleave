## 1. 共通ルール

| 項目 | ルール |
|---|---|
| 主キー | `id`（UUID、`gen_random_uuid()`で採番）。関連テーブル（多対多）は複合主キー |
| 命名 | テーブル名・カラム名はスネークケース、テーブル名は複数形 |
| 日時 | `timestamptz`型、UTCで保存。`created_at`／`updated_at`を原則全テーブルに持つ |
| 所有者 | 全データは`user_id`、またはキャラクター経由で`user_id`に紐づく |
| 削除 | 物理削除。削除前の内容は`change_histories`に残るため、復元はそこから行う |
| 外部キー | 親が消えたら子も消えるもの（イラスト等）は`ON DELETE CASCADE`、それ以外は個別に定義 |
| 列挙値 | DBでは`varchar`で保持し、取りうる値はアプリ側（Zod）とCHECK制約で制限する |

## 付録：Prismaスキーマ

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id           String   @id @default(uuid()) @db.Uuid
  email        String   @unique @db.VarChar(255)
  passwordHash String   @map("password_hash") @db.VarChar(255)
  displayName  String   @map("display_name") @db.VarChar(50)
  createdAt    DateTime @default(now()) @map("created_at") @db.Timestamptz
  updatedAt    DateTime @updatedAt @map("updated_at") @db.Timestamptz

  settings          UserSetting?
  resetTokens       PasswordResetToken[]
  characters        Character[]
  tags              Tag[]
  terms             Term[]
  episodes          Episode[]
  relationships     Relationship[]
  histories         ChangeHistory[]
  publicSetting     PublicSetting?
  consistencyChecks ConsistencyCheck[]

  @@map("users")
}

model UserSetting {
  userId             String     @id @map("user_id") @db.Uuid
  theme              String     @default("dark") @db.VarChar(20)
  sidebarCharacterId String?    @map("sidebar_character_id") @db.Uuid
  aiCheckEnabled     Boolean    @default(false) @map("ai_check_enabled")
  aiCheckConsentedAt DateTime?  @map("ai_check_consented_at") @db.Timestamptz
```
