# Artリーブ 操作デモ

案A（フィルム写真）デザインで、画面の流れと演出を確かめるための動くデモです。サーバーもDBも使わず、`index.html` をブラウザで開くだけで動きます。

## できること

- ログイン（入力済みのまま「ひらく」で入れる）
- 図鑑：検索、タグでの絞り込み、並び替え
- キャラ詳細：本の見開き。初回はパラパラめくってから開き、前後のキャラ・インデックスの切り替えでページがめくれる（左右キー・スワイプ対応）
- キャラの追加・編集・削除：イラストのアップロード、タグ、カラーパレット、マネキン（身長・頭身・体格）

データは開いた人のブラウザ（localStorage）にだけ保存されます。図鑑の下の「サンプルの状態に戻す」で初期状態に戻せます。

## 開き方

`demo/index.html` をダブルクリックしてブラウザで開きます。フォントは Google Fonts から読み込むため、オフラインではゴシック・明朝の代わりのフォントで表示されます。

ログイン画面の写真は作者が撮影したものです。
